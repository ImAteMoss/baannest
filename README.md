# BaanNest 🏡

BaanNest is a full-stack real estate marketplace and property management platform designed for the Thai property market.

🌐 **Live Demo:** https://baannest.vercel.app

## About the Project

I developed BaanNest to make property searching, listing, and real-estate management more organized and convenient.

The platform supports property seekers, owners, agents, and internal administrators through different workflows.

## Key Features

- Property search for rent and sale
- Advanced filtering by price, property type, bedrooms, bathrooms, and location
- Property listing creation and photo management
- User authentication and profiles
- Saved properties
- Property enquiry system
- Owner and agent property management
- Admin dashboard
- Lead and deal management
- Rental contract preparation workflow
- Thai property location database
- Responsive web interface
